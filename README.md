# 024 · Hoshiyomi Seven Reboot 🔮

**QuestQueries #024** — デイリーログ × 七人の星読みたち

毎日のコンディションを記録し、星読みたちにAI診断してもらうアプリ群。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `024_form.html` | デイリーログ入力フォーム（毎日使う） |
| `024_hoshiyomi.html` | 星読みたちによるAI診断（週次） |

## 使い方

1. 毎日 `024_form.html` でその日のコンディションを記録
2. 週1でガーミンCSVをドロップして睡眠・HRVデータを更新
3. 気が向いたら `024_hoshiyomi.html` で星読みたちに診断してもらう

---

## 七人の星読みたち

7人がそれぞれの視点と口調で、あなたの1週間を読み解く。

| | 名前 | キャッチ | ひとこと |
|---|---|---|---|
| 🎙 | **るるるの部屋** | 好奇心全開・独自視点 | 「まあ！それ、どういうこと？」天真爛漫な角度から本質を突いてくる |
| 🔥 | **熱血兄弟** | テンション全開・実況系 | 「いいんですか？いいんです！」データをスポーツ実況のように読み上げる |
| 🌸 | **ゆるまる小学生** | 脱力・でも本質つく | 「なんか…ちょっとかわいそう」難しいことは言わないけど、なぜか正しい |
| 💅 | **松戸デラックス** | 毒舌・でも愛がある | 「ハッキリ言うけど」毒を吐きながら、最後は必ず味方になる |
| ⚽ | **元ミランの10番** | 自己啓発・ビッグマウス | 「可能性は0じゃないです」前向きなメッセージで鼓舞してくる |
| 🍚 | **よっしー先生** | 全肯定・養生の人 | 「それでええんです」料理の比喩でやさしく包んでくれる |
| 🔢 | **落合ゼロ** | データ一刀両断 | 「数字以外は全部感情ですよ」ガーミンの数値を直接引用する唯一のキャラ |

> **落合ゼロだけ**がガーミンCSVの実数値（HRV・睡眠スコアなど）を引用してコメントする設計になっている。他の6人は主観データを中心に読む。
